# NInfer-4090 v1.2.0 Release Notes

NInfer-4090 v1.2.0 specializes the runtime and operator pipelines for the NVIDIA GeForce RTX 4090 (sm_89, AD102). This release routes small-T and draft projections to Ada Tensor Cores, eliminates fractional wave quantization taxes across 128 SMs via Split-K and stream fork-join, adds MTP-compatible structured JSON output, establishes crash-safe physical VRAM budgeting under Windows WDDM, resolves upstream compatibility for updated checkpoints, and hardens serving and prompt cache reliability.

---

## What's Changed

### 1. Ada Lovelace (sm_89) Tensor Core & Operator Specialization
* **T=1 Draft Head Ada MMA (`src/ops/linear/q4/q4_small_t_mma.*`, `q4_dispatch.cpp`):** Routes MTP draft head projections at T=1 to double-buffered Ada Tensor Core MMA (`mma.sync.aligned.m16n8k16`) with `cp_async<16>`. Replaces scalar SIMT `q4_rowsplit_gemv_kernel`, mapping launches to 64.0 exact integer waves (8,192 blocks) across 128 SMs.
* **Split-K Integer Wave Scheduling (`src/ops/linear/q5/q5_small_t_mma.*`, `src/ops/linear/w8/w8_small_t_mma.*`):** Adds grid-level Split-K = 2 (`dim3(320, 2, 1) = 640` blocks) to `q5_small_t_mma_kernel` and `w8_small_t_mma_kernel` for cache-resident projections (MTP Attention Output, MTP Input, and residual down-projections). Accumulates via native BF16 atomicAdd, eliminating 2.5-wave quantization taxes and scheduling 5.0 exact integer waves on 128 SMs.
* **Attention Input Stream Fork-Join (`src/ops/attn_input_proj/`):** Co-schedules Q4 Query/Key (448 blocks) and Q5 Gate/Value (448 blocks) concurrently across two non-blocking streams using CUDA Graph-compatible cross-stream fork-join events. Maps the combined 896 blocks to exactly 7.0 integer waves across 128 SMs, eliminating idle trailing SMs.
* **Double-Buffered Small-T MMA Pipeline (`src/ops/linear/q4/q4_small_t_mma.cuh`, `src/ops/linear/q5/q5_small_t_mma.cuh`):** Implements asynchronous double-buffered shared memory staging with `cp_async` and `cp_wait<1>`, overlapping stage s+1 DRAM transfers with stage s Tensor Core execution. Routes small-T linear projections, fused residual adds, and standalone GDN/attention input projections (T in [2, 16]) away from scalar SIMT to Ada Tensor Cores.
* **In-CTA Epilogue Staging for GDN Projections (`src/ops/gdn_input_proj/q4_q5/q4_q5_gdn_input_conv_snapshot.cu`):** Implements `Q4GdnMmaConvEpilogue` and `Q5GdnMmaConvEpilogue` to stage distributed MMA column accumulators into shared memory, executing sequential 1D causal convolution and state publishing with coalesced 32-byte global transactions. Eliminates scalar `q5_rowsplit_gemm_simt_split4_kernel` and `q4_rowsplit_gemm_simt_kernel`.
* **W8 Small-T Register De-Choking & Smem Scale Staging (`src/ops/linear/w8/w8_small_t_mma.cuh`, `w8_config.h`):** Bounded loop unrolling to `min(kGroups, 4)` and unified scale staging to shared memory (`W8SmallTMmaScaleAccess::Shared`) with cooperative `cp_async`, eliminating 20 live 64-bit DRAM load pointers. Enforced `MinBlocksPerSm = 4` launch bounds for 128-thread schedules, reducing register allocation from 241 down to <= 128 and raising theoretical occupancy to 41.7% (20 warps).
* **GQA Decode Grid Wave Capping & Register Budget (`src/ops/launcher/gqa_attention_decode.cu`, `src/ops/kernel/gqa_attention_decode_i8.cuh`):** Extended the 1-resident-wave split cap (`kMax = 32 splits = 128 CTAs`) to query tokens 1..6 when context exceeds 4,096 tokens, eliminating 80 unneeded CTAs per launch. Enforced `MinBlocksPerSm = 2` launch bounds, reducing register allocation from 197 to exactly 128 registers per thread to double SM occupancy from 16.7% to 33.3%. Replaced intra-warp shared memory reduction loops with `__shfl_down_sync` register warp shuffles (eliminating 10 block barriers), and replaced dynamic-lane `__shfl_sync` broadcasts across sub-warps with direct `LDS` reads, eliminating out-of-line ABI calls (`CALL.ABS.NOINC`), stack frames, and 20 to 72 bytes of register spills across all 80 `TokenTile = 6` instantiations.
* **Shared-Activation Amortization (`src/ops/linear/q5/q5_linear_add_gemm_simt.cu`, `q5_rowsplit_gemm_simt.cu`):** Schedules two output rows per CTA across Q5 `split2` and `split4` SIMT decode GEMMs (`mlp/down`, GDN `value_z`, attention `gate_value`, and 6144-wide output projections). Amortizes BF16-to-FP32 conversion (`PRMT`) across two `FFMA` instructions, cutting PRMT instructions by 50% and global load sectors by ~48%.
* **Prefill Warp Tile Squaring & Column-Tile-Major Rasterization (`src/ops/linear/q5/q5_rowsplit_gemm_mma.cu`):** Squares warp tiles (WM32 x WN32) on GDN and attention input projections to reduce `ldmatrix` register traffic. Applies column-tile-major CTA rasterization to SwiGLU `gate_up` GEMM so resident CTAs sweep all column tiles of a row band concurrently, keeping weight lines resident in the 72 MB L2 cache and cutting DRAM traffic.
* **Vectorized 16-Byte Weight Staging (`src/ops/linear/q5/`, `q4/`, `q6/`, `w8/`):** Indexes dense W8, Q4, Q5, and Q6 weight staging loops over 8-code chunks per thread via 16-byte vectorized stores (`store_vec`). Threads decode directly from registers without intra-warp shuffles (`__shfl_sync`), eliminating shared store instructions and loop trip overhead.
* **Dynamic Register Launch Bounds on Q5 SIMT (`src/ops/linear/q5/q5_linear_add_gemm_simt.cu`, `q5_rowsplit_gemm_simt.cu`):** Replaced rigid compile-time launch bounds on Q5 SIMT column tiles with dynamic targets up to 128 registers, eliminating local memory spills on wide column tiles.
* **Instruction Cache Residency (`src/ops/linear/q5/q5_rowsplit_gemm_simt.cu`):** Rolls the Q5 slab loop (`#pragma unroll 2`) with software register prefetching, reducing SASS footprint from 64 KB (4096 instructions) down to 15.8 KB (1008 instructions) to fit within the SM L1 instruction cache.
* **Q5 SIMT Split4 Verification Range Expansion (`src/ops/attn_input_proj/q4_q5/`, `src/ops/gdn_input_proj/q4_q5/`):** Instantiated Q5 `split4` kernels across the full T in [2, 16] verification band for attention `gate_value` and GDN `value_z`, eliminating fallbacks to slower unspecialized `r8_c8` kernels across intermediate SIMT revisions before Tensor Core migration.
* **Q5 Slab-Schedule Kernel Documentation (`src/ops/linear/q5/q5_linear_add_gemm_simt.cu`):** Corrected the internal rolled-versus-unrolled slab timing tables in kernel comments following dynamic register retuning, establishing accurate baselines for future scheduling passes.
* **Target Wave Sizing (`src/core/device.h`):** Replaces hardcoded 170-SM grid allocations with cached `device_sm_count()` (128 SMs on RTX 4090 AD102) across GQA decode splits, RoPE, and prefill launchers, eliminating fractional straggler waves.
* **GDN Gating Projection Retuning (`src/ops/gdn_input_proj/bf16/`):** Schedules BF16 GDN gating projection at 8 warps (64 registers, 2 CTAs/SM) and sizes grid budgets to live SM count, adding automatic demotion fallback for smaller SM counts.
* **Causal Convolution Route Cleanup (`src/ops/causal_conv1d/`):** Removes sequential `causal_conv1d_sequence_launch` for T in [17, 64], setting `kCausalConvParallelMaxTokens = 16` so T > 16 routes directly to the parallel prefill kernel.

### 2. WDDM Residency Management & Physical VRAM Safeguards
* **Crash-Safe D3D12 Residency Fallback (`src/core/arena.cu`, `tests/test_arena.cpp`):** Fixes #10 by freeing allocated resources (`cudaFree`, `cudaDestroyExternalMemory`) and clearing sticky error state (`cudaGetLastError`) when D3D12 residency read-back probe fails, leaving the CUDA context pristine for subsequent `cudaMalloc` allocations.
* **Physical Dedicated VRAM Floor (`src/core/arena.cu`):** Bounds D3D12 residency allocations to physical adapter dedicated memory minus a 512 MiB DWM floor, preventing Windows WDDM from importing unbacked system pagefile heaps into CUDA.
* **Fast Capacity Rejection (`src/core/arena.cu`):** Added instant capacity checks in `DeviceArena::DeviceArena` to reject allocations exceeding physical adapter VRAM in under 1 ms, preventing multi-second Windows pagefile paging delays.
* **First-Class CLI Residency Flag (`apps/ninfer.cpp`, `apps/ninfer-serve.cpp`, `src/core/registry.cpp`):** Replaced implicit `NINFER_WDDM_EVICTABLE_BUDGET` environment variable with explicit `--wddm-evictable-budget` CLI option and `EngineOptions` field, keeping disabled by default for standard lazy `cudaMalloc` allocation.
* **Desktop-Shared GPU Residency Safeguards (`src/core/arena.cu`):** PR #7 made WDDM residency opt-in for desktop-shared GPUs, added synchronization on `EnqueueMakeResident` fences, and implemented head and tail pattern read-back verification before arena activation.
* **Touch-Fill Stream Synchronization (`src/core/arena.cu`, `src/core/pinned_host_buffer.h`):** PR #9 added `cudaDeviceSynchronize()` after D3D12 final zero-fill and fallback touch-fill to eliminate race conditions with non-blocking stream DMA transfers (`load_stream`). Converted `PinnedHostBuffer` from write-combined to cacheable pinned memory (`cudaMallocHost`).

### 3. Checkpoint Compatibility & Model Architecture
* **Validate-Only DFlash2 Stub (`src/targets/qwen3_6_27b/impl/load/bindings.cpp`, `src/artifact/binder.h`):** Fixes #13 by implementing `bind_dflash2_stub()` with `TensorPlacement::ValidateOnly`. Safely consumes and validates all 66 `dflash2/*` tensors present in updated Hugging Face releases of `Qwen3.8-27B-NInfer` without allocating VRAM, creating device objects, or issuing GPU DMA transfers. Full VRAM remains available for KV caching.
* **Blackwell SM120 and NVFP4 Purge (`src/ops/`, `src/core/`, `src/artifact/`, `tools/`):** Surgically deleted 45+ SM120 NVFP4 kernel files, TMA loaders, container parser descriptors, test fixtures, model cards, and conversion scripts, keeping the codebase strictly targeted to Ada Lovelace (`sm_89`).
* **Streamlined Repository Specification (`AGENTS.md`):** Refactored repository rules and architectural contracts, focusing exclusively on RTX 4090 sm_89 and Qwen models while codifying proven CUDA invariants.

### 4. Serving, Structured Generation & Protocol Enhancements
* **MTP-Compatible Structured JSON Output (`src/serve/`, PR #12):** Enforces grammar-based structured JSON generation in `ninfer-serve`. Scopes grammar masks strictly to the root prediction position, preserving Multi-Token Prediction speculative drafting during constrained generation.
* **In-Place Multi-Turn System Message Rendering (`src/targets/qwen3_6_27b/impl/runtime/chat_template.cpp`):** Renders mid-conversation system turns in place as ordinary system blocks instead of folding them into the leading turn or rejecting them. Eliminates prefix cache invalidations and restores prompt cache reuse for clients sending dynamic system reminders (e.g. Claude Code).
* **Maximal Subpart UTF-8 Error Recovery (`src/targets/qwen3_6_27b/impl/runtime/tokenizer.cpp`):** Implements Unicode standard W3C Section 5.22 maximal subpart error recovery in `consume_generated_utf8`, substituting malformed or truncated byte sequences across streaming chunk boundaries with `U+FFFD` without throwing unhandled exceptions.
* **Accurate Executor Health Reporting (`src/serve/http_server.cpp`, `src/core/concurrent_executor.h`):** Updated `/health` endpoint to query `ConcurrentExecutor::healthy()`, returning HTTP 503 with `{"status":"error"}` if the worker loop has latched a failure state.
* **Transient Admission Shortfall Recovery (`src/targets/qwen3_6_27b/impl/runtime/program_executor.cpp`):** Treats transient page shortages during lane admission as a normal scheduling condition rather than throwing `std::logic_error`, replanning requests without permanently latching executor failure.
* **Dynamic Token Bounds & Unconstrained Generation (`apps/ninfer-serve.cpp`):** Dynamically defaults `default_max_tokens` to `options.max_context` when omitted, supports `-1` for unconstrained generation, and exposes `n_predict: -1` in `/props` for WebUI slider initialization.
* **Embedded WebUI Update (`cmake/ninfer_ui.cmake`):** Updated embedded WebUI static assets to release tag `b10655` with automatic CMake cache synchronization.
* **Draft Proposal Head Documentation (`apps/ninfer.cpp`, `apps/ninfer-serve.cpp`):** Corrected CLI documentation for `--lm-head-draft` to state that it drafts via the dedicated proposal head rather than reusing the full base LM head.

### 5. Prompt State Cache & DirectStorage 1.3 Hardening
* **Bounded 32-Page Snapshot Staging (`src/core/disk_state_cache.cpp`, PR #6):** Chunks VRAM staging allocations during disk state cache save and restore into bounded 32-page batches, eliminating out-of-memory errors on 24 GB cards during deep-context operations.
* **MTP KV Cache Stride Fix (`src/core/disk_state_cache.cpp`):** Corrects MTP KV restore page stride calculations using total pool page dimensions (`mtp_pool.total_page_bytes()`), preventing data corruption on partial snapshot restores.
* **Streamlined Chunked Save Staging (`src/core/disk_state_cache.cpp`):** Streams asynchronous Text KV chunks directly into destination buffers without inner-loop host allocation and synchronization stalls.
* **Committed Snapshot Publication (`src/core/disk_state_cache.cpp`):** Modifies cancellation handling to publish completed on-disk page writes rather than discarding them when higher-priority inference requests arrive.
* **On-Device Alignment Tokens (`src/targets/qwen3_6_27b/impl/runtime/mtp_prefill.cpp`):** Replaces synchronous stream drains and host memory transfers with asynchronous device-to-device `cudaMemcpyAsync` from `io_.token` into `mtp_ids`, keeping alignment tokens on the stream.

### 6. Build System & Toolchain Optimizations
* **Whole-Program Device Optimization (`CMakeLists.txt`):** Disables relocatable device code (`-rdc=false`) across `ninfer_core` and `ninfer_ops`, enabling whole-program optimization, global load pipelining across loop back edges, and removing the serialized device link step. Makes `-Xptxas=-v` unconditional across all platforms.
* **Multi-Threaded Parallel CUDA Compilation (`CMakeLists.txt`):** Added `--split-compile=0` to CUDA compiler flags, parallelizing `cicc` and `ptxas` device code assembly across all available CPU threads and eliminating single-threaded build bottlenecks.
